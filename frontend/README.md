# Frontend Application — Next.js

Client-side user interface for the Municipal Complaint Management System (MCMS).

## Key Portals & Features
- **Citizen Portal**:
  - Complaint submission with input validation & instant error corrections.
  - Tracking & Inquiry dashboard by complaint ID / citizen phone.
- **Staff / Worker View**:
  - Assigned work order list and inspection updates.
  - Action taken entry and status resolution.
- **Admin & Supervisor Dashboard**:
  - Department overview & workload balance metrics.
  - Decision-support alert center (review and approve/reject flagged actions).
  - Analytical reports on resolution time and pending backlogs.

## Quickstart

```bash
cd frontend

# Install dependencies
npm install

# Setup environment
copy .env.example .env.local

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
